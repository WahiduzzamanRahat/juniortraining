# Outpost One · Junior Astronaut Mission Trainer

**Team: WILL of D(ebug)**  
**NASA Space Apps Challenge 2026 challenge: [Build a Junior Astronaut Mission Trainer](https://www.spaceappschallenge.org/2026/challenges/build-a-junior-astronaut-mission-trainer/)**

Outpost One is a short, interactive training game for young explorers. Choose a lunar or Martian outpost, name your crew, and make five daily decisions while balancing oxygen, power, food, and protection. Your mission log and final reserve score show how each trade-off shaped the outcome.

The game uses a deliberately simplified, fixed scenario model for learning and discussion. It is not a mission-planning or life-support engineering tool. The Moon and Mars scenarios are inspired by the challenge’s focus on life support, radiation shielding, power, and food production.

## Run locally

Open `index.html` in a modern browser. This is a single static file: no server, API key, build step, or database is required.

## Publish free with GitHub Pages

1. Create a **public** GitHub repository and upload `index.html` and this `README.md`.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)`, then click **Save**.
5. Wait for GitHub to show the Pages URL on that screen, then open it and play through the game.

GitHub Pages is available on GitHub Free for public repositories. The site itself has no paid hosting or AI API dependency.
